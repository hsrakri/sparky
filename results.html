What actually fought back

Seven challenges,
zero unsolved.

The honest engineering log — each one cost real time, each one is reproducible, each one has a fix in the recipes.

memory semantics

“0.45 + 0.45” is a race, not a partition

vLLM’s --gpu-memory-utilization is a per‑process reservation checked against free memory at startup. Two instances launched together fight the profiler; the loser dies with No available memory for the cache blocks.

Solved: fractions sum ≲ 0.88, sequential startup, coder first — codified in vllm-stack-up.sh.

deadlock

CUDA‑graph capture hangs when co‑located

Nemotron’s torch.compile / graph‑capture path froze at boot every time a second model was resident — banner printed, memory flat, nothing loaded, no error. The nastiest kind of failure: silent.

Solved: --enforce-eager for the orchestrator. Costs decode speed, boots 100% of the time.

found a real bug

Speculative decoding breaks tool‑call parsing

On vLLM v0.26.0, n‑gram spec‑decode + the qwen3_coder parser returns name="get_weather(city=…)" with empty arguments — at temperature 0, reproduced at k=3 and k=5, clean without spec. A genuine serving‑stack interaction bug.

Solved (worked around): agent config ships without spec‑decode; documented as pure‑codegen‑only. 1.9× left on the table until the parser interaction is fixed upstream.

model behavior

The coder over‑iterates on hard algorithms

On Myers diff, min‑max heaps, and thread‑safe pools, the delegated coder loops — 17–36 calls refining instead of converging — and blows its time budget. 100% of both nights’ failures trace to this one behavior.

Mitigable: iteration caps or per‑task budgets; the per‑problem data makes hard tasks routable.

reasoning tax

The orchestrator thinks 169 tokens to say “PONG”

Reasoning models reason — even on trivial prompts. Hidden thinking consumed whole token budgets and made early benchmarks look like empty responses.

Solved: reasoning_effort: none at the agent layer + generous budgets; “detailed thinking off” only trims it.

harness lesson

Delegated agents write files, not stdout

Benchmark harnesses that parse the orchestrator’s chat output see summaries, not code — the sub‑agent wrote solution.py to disk all along. Cost three harness rewrites at 2 a.m.

Solved: make the file the artifact — instruct a canonical path, read the file, keep round‑2 prompts short so the orchestrator delegates instead of over‑reasoning.

physics

Dense 27B ≈ 12 tok/s. That’s the roofline, not a bug.

273 GB/s ÷ ~14 GB of active NVFP4 weights ≈ 20 tok/s ceiling; we measured 11.6 co‑located. No flag fixes bandwidth — only fewer active bytes (MoE) or accepted drafts (speculation) do.

Accepted: the orchestrator fronts the conversation at ~50 tok/s while the strong‑but‑slow coder works in the background — the architecture absorbs the physics.
