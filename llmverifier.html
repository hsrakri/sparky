The Fix, in Brief

What broke On a vLLM server with a reasoning parser (every self-hosted DeepSeek / GLM), the prefilled score letter arrives in message.reasoning, not message.content — so the library read an empty letter and every score fell back to 0.5. No error raised.

The change Read the letter from the reasoning field (and, failing that, the logprobs); never let an empty token shadow the captured score distribution. Reproduced independently on DeepSeek-V4-Flash (ours) and GLM-5.2 — filed as issue #5 and PR #7.
